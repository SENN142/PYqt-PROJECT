# Умный каталог медиа (Media Catalog)

**Выполнил:** студент 3 курса Кулякин Арсентий.

Десктопное приложение с графическим интерфейсом для учета и каталогизации фильмов, сериалов, игр и книг. Проект позволяет вести личную библиотеку, добавлять обложки (постеры) и выставлять оценки произведениям.

## 🛠 Технологии и стек
* **Язык:** Python 3.10+
* **GUI Фреймворк:** PyQt5 (интерфейсы спроектированы в QtDesigner)
* **База данных:** SQLite3 (встроенная реляционная СУБД)
* **Сборка .exe:** PyInstaller

---

## ✅ Реализация требований ТЗ (Критерии оценивания на 20 баллов)

В данном проекте полностью реализованы все пункты технического задания:

### 1. Документация (2 балла)
* `requirements.txt` сгенерирован и содержит точные версии библиотек для сборки.
* Подробный `README.md` с описанием архитектуры и инструкцией по запуску.

### 2. Качество кода (6 баллов)
* **Архитектурная сложность:** Код разбит на логические модули:
  * `main.py` — точка входа и запуск приложения.
  * `windows.py` — ООП-классы `MainWindow` и `EditDialog`, отвечающие за логику интерфейса.
  * `db_manager.py` — модуль инкапсуляции SQL-запросов и работы с БД.
* **Стиль кода:** Код написан с соблюдением стандартов PEP8, используются говорящие имена переменных (например, `delete_selected_record`, `category_mapping`). Выделена константа `DB_NAME`.
* **Документирование:** К каждому классу и функции написаны подробные Docstrings.

### 3. Технологии (10 баллов)
* **a. Не менее двух форм:** Используются файлы `main_window.ui` (главное окно) и `edit_dialog.ui` (окно добавления), созданные в QtDesigner.
* **b. Не менее 5 различных виджетов:** В проекте применены `QTableWidget`, `QPushButton`, `QComboBox`, `QSpinBox`, `QLineEdit`, `QLabel`.
* **c. Стандартные диалоги:** 
  * `QMessageBox.question` — для подтверждения удаления записи.
  * `QFileDialog.getOpenFileName` — для выбора изображения постера.
* **d. Наличие мультимедиа:** Программа умеет загружать, масштабировать и отображать изображения (постеры) с помощью класса `QPixmap`.
* **e. Работа с БД (>= 2 таблиц):** База данных `media_catalog.db` содержит две связанные таблицы: `categories` (справочник жанров) и `media` (основные записи). Реализованы функции чтения, записи и удаления.
* **f. Обработка клавиатуры:** В `MainWindow` переопределен `keyPressEvent`. При нажатии клавиши **Delete** вызывается удаление выделенной строки из таблицы и БД.
* **g. Обработка мыши:** В `EditDialog` переопределен `mousePressEvent`. При клике левой кнопкой мыши по пустому месту окна снимается фокус с полей ввода.

### 4. Standalone версия (2 балла)
Приложение скомпилировано в единый `.exe` файл. В коде реализована функция `resource_path()` для динамического поиска файлов `.ui` во временных папках среды PyInstaller, что гарантирует стабильный запуск без сторонних файлов.

## 🚀 Инструкция по запуску (из исходников)

1. **Склонируйте репозиторий:**
   ```bash
   git clone <вставьте_ссылку_на_ваш_репозиторий>
   cd MediaCatalog
   ```

2. **Создайте и активируйте виртуальное окружение (рекомендуется):**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для Mac/Linux:
   source .venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите проект:**
   ```bash
   python main.py
   ```
   *(При первом запуске база данных `media_catalog.db` будет создана и заполнена базовыми категориями автоматически).*

## 📦 Сборка Standalone (.exe) версии

Если вы хотите собрать `.exe` файл самостоятельно, выполните следующие команды:
```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --add-data "ui;ui" main.py
```
Скомпилированный файл появится в директории `dist`.
