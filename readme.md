# Умный каталог медиа (Media Catalog)

**Выполнил:** студент 3 курса Кулякин Арсентий.

Десктопное приложение с графическим интерфейсом для учета и каталогизации фильмов, сериалов, игр и книг. Проект позволяет вести личную библиотеку, добавлять обложки (постеры), выставлять оценки, искать нужные записи и экспортировать данные.

## 🛠 Технологии и стек

* **Язык:** Python 3.10+
* **GUI Фреймворк:** PyQt5 (интерфейсы спроектированы в QtDesigner, дизайн кастомизирован через QSS-стили)
* **База данных:** SQLite3 (встроенная реляционная СУБД)
* **Сборка .exe:** PyInstaller
* **Дополнительно:** Модули `csv` (для экспорта), `logging` (для аудита событий).

## ✨ Основной функционал
* Просмотр списка медиа в виде удобной таблицы с возможностью сортировки.
* Поиск записей по названию.
* Добавление новых записей с указанием категории, названия, рейтинга и постера.
* Безопасное удаление записей (в том числе горячей клавишей `Delete`).
* Подсчет и вывод статистики (общее количество медиа, средний рейтинг).
* Экспорт всей базы данных в формат CSV.
* Фоновое логирование всех действий пользователя в файл `app.log`.

## ✅ Реализация требований ТЗ (Критерии оценивания на 20 баллов)

В данном проекте полностью реализованы все пункты технического задания:

### 1. Документация (2 балла)
* `requirements.txt` сгенерирован и содержит точные версии библиотек для сборки.
* Подробный `README.md` с описанием архитектуры, инструкцией по запуску и ТЗ.

### 2. Качество кода (6 баллов)
* **Архитектурная сложность:** Код разбит на логические модули (`main.py`, `windows.py`, `db_manager.py`, `logger.py`). Используется ООП (классы `MainWindow`, `EditDialog`).
* **Объем кода:** Написано **более 500 строк** содержательного кода (реализованы стили оформления, экспорт в CSV, логирование, поиск).
* **Стиль кода:** Код соответствует стандартам PEP8, используются говорящие имена переменных. Выделена константа `DB_NAME`.
* **Документирование:** К каждому классу и функции написаны подробные Docstrings.

### 3. Технологии (10 баллов)
* **a. Не менее двух форм:** Используются файлы `main_window.ui` и `edit_dialog.ui` (QtDesigner).
* **b. Не менее 5 различных виджетов:** В проекте применены `QTableWidget`, `QPushButton`, `QComboBox`, `QSpinBox`, `QLineEdit`, `QLabel`, `QHeaderView`.
* **c. Стандартные диалоги:**
  * `QMessageBox` (информация, подтверждение удаления, ошибки).
  * `QFileDialog.getOpenFileName` (выбор постера).
  * `QFileDialog.getSaveFileName` (сохранение CSV).
* **d. Наличие мультимедиа:** Программа загружает, масштабирует и отображает изображения (постеры) через `QPixmap`.
* **e. Работа с БД (>= 2 таблиц):** База данных `media_catalog.db` содержит две связанные таблицы: `categories` (жанры) и `media` (записи). Реализованы чтение, запись, изменение, поиск и агрегатные функции.
* **f. Обработка клавиатуры:** В `MainWindow` переопределен `keyPressEvent` (`Delete` - удаление строки, `Escape` - сброс поиска).
* **g. Обработка мыши:** В `EditDialog` переопределен `mousePressEvent` (клик по фону снимает фокус с полей ввода).

### 4. Standalone версия (2 балла)
Приложение скомпилировано в единый `.exe` файл. В коде реализована маршрутизация `resource_path()` для корректного извлечения файлов `.ui` из временных папок PyInstaller.

## 🚀 Инструкция по запуску (из исходников)

1. **Склонируйте репозиторий:**
   ```bash
   git clone <вставьте_ссылку_на_ваш_репозиторий>
   cd MediaCatalog
   ```
2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Для Windows
   ```
3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Запустите проект:**
   ```bash
   python main.py
   ```
   *(При первом запуске база данных будет создана автоматически, также появится папка `logs` с файлом аудита).*
